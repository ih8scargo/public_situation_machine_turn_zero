## Persistence and scope boundary

`CrossingRehearsal` stores reversible pull/feed state under `crossing_rehearsal`
with optimistic revisions. Upon receipt it uses the existing opening's retained
prerequisites and single Pointing-able appointment. It prepares the original PULL/
first-PUFFING prerequisites only if absent; no later PUFFING occurs and no bellows
camera is required of the Human. The received stick contains the curved samples,
endpoint, direction, nozzle dimensions and Doll-mediated ancestry. It is not erased
when geometry is occluded or the pull is reversed.

it does not invent a paired pull that never occurred. A legacy bearing receives
an explicitly unresolved presentation adapter rather than being forced into this
quarter-circle. Reference rendering also retains the curved shape when present.
The default bounded route rejects later-operation events server-side. Other
historical reference modes remain available for inspection; none are entered
automatically. Historical reference suites exercise already-built behavior only
as isolated regression checks, not as a continuation of this geometry workflow.
