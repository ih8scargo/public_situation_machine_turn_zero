## Content digest compatibility

Artifact comparison exposed that the earlier `CoBuilding.digest/1` hashed JSON objects in runtime map enumeration order. Identical source meshes could receive different hashes in separate VM runs. V10 now names `co-building-canonical-json-v1`: recursively typed atom/list/tuple values and maps encoded as sorted typed key/value pairs before SHA-256. Source IDs and meshes are preserved; old v7/v8/v9 digest strings are historical encoding outputs and must not be compared directly with canonical v10 strings. No prior export is rewritten. Preservation checks compare their actual finite source meshes and IDs. Source identity checks across v10 views/reloads use the canonical profile.
