## The four relations

**DOWN / FROM** is a floor outreading of saved `standing.from` plus actual inherited
relations. At DOWN, the complete same source relation set is recoverable at every
NAV position, including after reversal. It is not a floating metadata card.

**UP / ALONG THROUGH** derives its inscription from the existing ZEROETH–ONE
Tunnel record (`from`, `toward`). The overhead course is revealed by upward
Regard; it is not permanently pasted across the scene. Reverse velocity does
not reverse that source/target relation.

**XT / context** resolves actual associations: authored source history, furnished
relations explicitly referenced by material dependencies, and already-authored
same-origin groundward/CONTINUING FROM material. Missing dependencies do not
become invented relations. With no held sheet, XT may inspect existing contextual
standing of the current Tunnel extent. The leaf sweeps spatially through/off the
sheet/aperture, not into an alternate page or fixed sidebar. All writing comes
from existing records; no semantic interpretation or generated explanation is
introduced.

**YT / encountered material** privileges the identity explicitly taken up by the
Human. Bobbing does not choose a sheet based on text, proximity alone or velocity.
Returning from XT/DOWN/UP retains that same target. The Inner Aperture supplies
readable resolution, not a new material copy.

## Stable geometry and bounded Calibrationing

The aperture's four members and the elbow course remain system geometry. A Human
can adjust readable resolution only within **0.85–1.15**:

- focus the Inner Aperture and press plus/minus; or
- Ctrl+wheel on the Inner Aperture itself.

This changes bounded readable type scale and local aperture extent, never FROM,
TOWARD, source identity, ancestry or course. The range is shared in memory across
Tunnel views during the running app visit, so it is not recalibrated per Tunnel.
Reload clears that transient profile. No settings panel, localStorage record or
constitutional calibration law was added.

NAV tack distribution now derives from the existing course extent and sheet
count, within a bounded visual range. It supplies pace/direction feedback without
semantic tack identities, mandatory stops or consequential extent counting.
The two Rails, tack lattice and actual floor provenance remain distinct geometry.
